## 功能

- **文件夹树导航** —— 完整保留原始目录结构，可展开/收起；剧场版中 MyGO!!!!! 固定显示在 Ave Mujica 之前，漫画游戏区按资料类型归组，同类型内保持 MyGO!!!!! → Ave Mujica
- **Markdown 渲染** —— 标题、表格、引用、嵌套列表都正常显示
- **纯文本查看** —— 剧情 `.txt` 按剧本格式等宽呈现
- **全库搜索** —— 按 `/` 或 `Ctrl/⌘ + K` 唤起，即时过滤 135 个文件
- **本文大纲** —— 右侧自动生成目录，带滚动高亮
- **交叉引用跳转** —— 正文里提到的 `灯x祥子.md` 这类文件名自动变成可点链接
- **角色代表色** —— 卡片配色取自各角色人设（灯 `#77BBDD`、祥子 `#7799CC`…）
- **动画剧本按对白排版** —— `01_MyGO动画` 的 13 集台词底稿在页面上拆成说话人与台词两栏，动作提示、旁白与笔记各自区分；每集顶部带[官方网站](https://anime.bang-dream.com/mygo/story/)的场面图、日文原标题、梗概、代表台词与制作名单
- **两部动画的完整剧情核验** —— 以《It's MyGO!!!!!》与《Ave Mujica》各 13 话的完整情节为共同基线，结合官方资料、全 13 话完整字幕（Its-MyPicDB）、逐帧字幕及详细逐话记录，交叉核对跨作回忆、人物到场、话数边界、动作和对白；Ave Mujica 总纲已逐话按场景重写：每段对白一人一段、标明说话人、尽量用字幕原句，短信与消息逐条打出，剧中剧与歌词完整收录，插曲视频放在歌曲响起处，场面截图分散在正文里不扎堆；说话人经字幕、逐话记录与站长看片核对，文末保存 12 篇逐话底稿链接；感想、推测、CP 评论与剧情事实分开处理
- **手游对白归档** —— 保存 MyGO!!!!! 的 41 章英文乐队故事，并逐项归档《少女乐团派对！》中 MyGO!!!!! 成员登场的 10 期活动及两期 MyGO!!!!! × Ave Mujica 前后篇，共 92 章国服中文主线对白、场景与转场提示
- **逐文件更新时间** —— 文件夹清单与阅读页均显示精确到分钟的北京时间；已提交文件按 Git 最后修改提交计时，未提交文件按生成时刻计时，不采用检出时会变化的文件系统 mtime；剧本的配图、资料卡写在 `assets/episode-meta.json` 里，其中某个条目有改动时，也会刷新对应文件的更新时间；阅读页更新时间后还会写出「最近改动」——即最近一次改动该文件的提交标题，尚未提交的改动取构建时 `python3 tools/build_manifest.py --note "说明"` 传入的说明
- **社区材料边界** —— 社区汇总区分剧情事实、主创原话与评论推论；资料库编辑正文不把角色解读写成临床诊断；社区原帖中的诊断式猜测、自杀风险预测、网络黑话和尖锐措辞可以作为接受史保留，但须明确标为原作者观点。重复长文只保留一份全文，其余位置改用摘要与跨文件索引
- **目录状态标记** —— 金色锁（`01_MyGO动画`、`02_AveMujica动画`）表示已定稿：剧情、配图与资料均已逐项核对，内容固定，无需再改；「更新中」标签（`03_剧场版`、`04_漫画游戏`、`05_官方访谈与设定`、`06_社区解析_推测`、`07_CP线梳理`）表示内容会随新资料持续补充
- **配图** —— 角色人设配官方立绘，CP 单篇配双方立绘，已核验画面的桥段用真实场景截图；剧情文件按小节配图，图注里的话数以逐帧字幕时间码核对过；图片加载失败会显示图注与原图链接，不留空白
- **深浅色主题** —— 跟随系统，也可手动切换
- **阅读位置恢复** —— 浏览器后退或前进时回到离开前的位置
- **离线阅读** —— 下载完整仓库后可直接双击 `index.html`
- **响应式** —— 手机上侧栏变抽屉
- **按需返回按钮** —— 正文里发生跳转时，窄屏右下角才浮出返回按钮：本页跳转显示「返回」回到原位置，跨文件跳转显示「上一页」回到来源文件；有文内目录的长文另有「目录」按钮。没有跳转就不出现

## 添加到 iPhone / iPad 主屏幕

在 **Safari** 里打开在线地址，点底部的「分享」→「添加到主屏幕」，确认「作为 App 打开」（Open as Web App）已开启，再点「添加」。之后从主屏幕图标打开，会以独立窗口全屏显示，没有地址栏；已经访问过的页面在没有网络时也能读（远程图床的图片除外）。

如果之前已经加过快捷方式、点开仍跳到 Safari，那是旧的书签式快捷方式：先在主屏幕上删掉它，再按上面的步骤重新添加。相关文件：`manifest.webmanifest`、`sw.js`、`assets/icons/`。

## 技术说明

纯静态站点，**没有构建步骤、没有外部依赖**，直接用原生 HTML/CSS/JS：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架 |
| `assets/style.css` | 样式（CSS 变量控制主题） |
| `assets/app.js` | 文件树、路由、Markdown 渲染器、搜索 |
| `assets/manifest.json` | 目录清单，由脚本生成 |
| `assets/offline-data.js` | 本地双击时使用的目录、正文、视频与剧集元数据 |
| `assets/video-meta.json` | Bilibili 视频标题、封面等展示元数据 |
| `assets/episode-meta.json` | 剧本与视角长文的排版、资料卡、配图和站内互见链接 |
| `tools/build_manifest.py` | 扫描 `资料库/`，重新生成清单、离线数据与文件大纲 |
| `.nojekyll` | 关闭 Jekyll，确保中文路径正常提供 |

页面直接读取 `assets/offline-data.js`，因此通过网站访问或双击本地文件时都使用同一份目录与正文数据。

### 增删资料后

```bash
python3 tools/build_manifest.py
```

脚本会同时更新 `assets/manifest.json`、`assets/offline-data.js` 与 `资料库/项目文件大纲.txt`，并刷新 `index.html` 里的静态资源版本号。这三个文件都由脚本生成，不要手工修改。

### 正文里的跳转

- **本页跳转** —— 写 `[章节名](#章节名)`，锚点按标题文字匹配；跳转目标标题会自动获得行内「返回目录」小按钮
- **跨文件跳转** —— 写 `[说明](../目录/文件.md)`，或在正文里直接写出 `灯x祥子.md` 这类文件名，交叉引用会自动转成站内链接

两种写法都会让窄屏右下角按需浮出返回按钮，正文里不需要加任何额外标记。今后新增带跳转的资料后，请在手机宽度下点一次跳转，确认「返回 / 上一页」能回到原处。

### 折叠长篇转载

```markdown
@[details](展开原文)
默认收起的内容，支持完整 Markdown。
@[/details]
```

整段转载外部讨论时，推荐「概述几条主要观点 + 原帖链接 + 原文放进折叠块」的写法：原文一字不少，又不会把正文淹掉。

### 本地阅读

下载完整仓库后可直接双击 `index.html`。如果希望用本地服务器预览，也可运行：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```
