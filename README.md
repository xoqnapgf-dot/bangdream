**在线访问：** https://xoqnapgf-dot.github.io/bangdream/

[项目简介、阅读与维护注意事项](./项目简介.txt)

## 功能

- **文件夹树导航** —— 完整保留原始目录结构，可展开/收起
- **Markdown 渲染** —— 标题、表格、引用、嵌套列表都正常显示
- **纯文本查看** —— 剧情 `.txt` 按剧本格式等宽呈现
- **全库搜索** —— 按 `/` 或 `Ctrl/⌘ + K` 唤起，即时过滤 134 个文件
- **本文大纲** —— 右侧自动生成目录，带滚动高亮
- **交叉引用跳转** —— 正文里提到的 `灯x祥子.md` 这类文件名自动变成可点链接
- **角色代表色** —— 卡片配色取自各角色人设（灯 `#77BBDD`、祥子 `#7799CC`…）
- **目录状态标记** —— `01_MyGO动画`、`02_AveMujica动画`、`05_官方访谈与设定` 显示全锁（原始资料），`06_社区解析_推测` 显示全锁（社区解析），`03_剧场版`、`04_漫画游戏` 显示半锁（阶段性整理）
- **深浅色主题** —— 跟随系统，也可手动切换
- **阅读位置恢复** —— 浏览器后退或前进时回到离开前的位置
- **离线阅读** —— 下载完整仓库后可直接双击 `index.html`
- **响应式** —— 手机上侧栏变抽屉；长文可用浮动“目录”按钮返回文内目录

## 技术说明

纯静态站点，**没有构建步骤、没有外部依赖**，直接用原生 HTML/CSS/JS：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架 |
| `assets/style.css` | 样式（CSS 变量控制主题） |
| `assets/app.js` | 文件树、路由、Markdown 渲染器、搜索 |
| `assets/manifest.json` | 目录清单，由脚本生成 |
| `assets/offline-data.js` | 本地双击时使用的目录、正文与视频元数据 |
| `assets/video-meta.json` | Bilibili 视频标题、封面等展示元数据 |
| `tools/build_manifest.py` | 扫描 `资料库/`，重新生成清单、离线数据与文件大纲 |
| `.nojekyll` | 关闭 Jekyll，确保中文路径正常提供 |

页面直接读取 `assets/offline-data.js`，因此通过网站访问或双击本地文件时都使用同一份目录与正文数据。

### 增删资料后

```bash
python3 tools/build_manifest.py
```

脚本会同时更新 `assets/manifest.json`、`assets/offline-data.js` 与 `资料库/项目文件大纲.txt`，并刷新 `index.html` 里的静态资源版本号。这三个文件都由脚本生成，不要手工修改。

### 本地阅读

下载完整仓库后可直接双击 `index.html`。如果希望用本地服务器预览，也可运行：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```
