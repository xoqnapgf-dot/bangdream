# 一、项目是什么
+
+把一份 **MyGO!!!!! × Ave Mujica 同人资料库**（135 个 md/txt 文件）做成
+**网页版文件浏览器** —— 左边文件夹树，点开在右边看内容。
+
+- **仓库**：`xoqnapgf-dot/bangdream`（public，默认分支 `main`）
+- **线上**：https://xoqnapgf-dot.github.io/bangdream/
+- **状态**：PR #1 已合并（`ee02768`），网站已上线
+
+---
+
+## 二、当前仓库结构
+
+```
+bangdream/
+├── index.html                 页面骨架
+├── .nojekyll                  关闭 Jekyll，保证中文路径可访问（勿删）
+├── README.md
+├── NEXT_SESSION.md            本文件
+├── assets/
+│   ├── style.css              样式，CSS 变量控制深浅色主题
+│   ├── app.js                 文件树 / 路由 / Markdown 渲染器 / 搜索
+│   └── manifest.json          目录清单（59 KB，由脚本生成，勿手改）
+├── tools/
+│   └── build_manifest.py      扫描 资料库/ 重新生成 manifest.json
+└── 资料库/                     135 个文件 / 19 个目录 / 约 2.2 MB
+    ├── 00_剧情区/
+    │   ├── 01_MyGO动画/           13 集逐集剧情（txt，剧本体，CRLF）
+    │   ├── 02_AveMujica动画/      剧情总纲 + 睦/祥子双视角
+    │   ├── 03_剧场版/             prima aurora

+    │   ├── 05_官方访谈与设定/     确证内容汇总
+    │   ├── 06_社区解析_推测/
+    │   └── 07_CP线梳理/

+
+**技术选型**：纯静态，**零依赖、零构建步骤**。原生 HTML/CSS/JS，
+Markdown 渲染器是手写的（在 `app.js` 里）。内容用 `fetch()` 按需加载，
+首屏只读 59 KB 的 manifest。

+## 四、⚠️ 已知问题（下次优先修）
+
+### 1. 图片不会出现在文件树里
+`tools/build_manifest.py` 第 17 行只索引文本：
+```python
+TEXT_EXT = {".md", ".txt"}
+```
+往 `资料库/` 里放图片，文件浏览器**不会列出**。
+**要做**：加图片扩展名 + 在 `app.js` 里写个图片查看器分支（类似 `viewFile()` 里对 `ext` 的判断）。
+
+### 2. Markdown 里的相对图片路径会裂 🔴
+`资料库/01_高松灯/x.md` 里写 `![](图片/灯.png)`，浏览器会去**站点根目录**找，
+而不是 md 所在目录，图片显示不出来。
+
+**修法**：`viewFile()` 里渲染完之后，把 `img[src]` 的相对路径按当前文件所在目录重写。
+大概就是在 `linkifyRefs(box)` 旁边再加一个 `fixRelativeSrc(box, node.path)`。
+
+**临时绕过**：md 里写从站点根算起的完整路径
+```markdown
+![灯](资料库/01_高松灯/图片/灯.png)
+```
+
+### 3. CP 内容全网公开（未决策）
+105 个角色文件里 **90 个是 CP 向内容**（带攻受向解读）。仓库是 public，
+现在这些**全部公开可访问**。当时问过用户，没给答复，默认全放了。
+如果后续想改：在 `build_manifest.py` 里加个过滤，或在前端加开关。

+## 六、环境限制（踩过的坑，别再踩）
+
+### 沙盒网络是白名单制
+```
+github.com                 ✅ 通（git / gh 用）
+raw.githubusercontent.com  ❌
+drive.google.com           ❌
+pan.baidu.com              ❌
+```
+**"让用户传网盘、agent 用 curl 下载"这条路走不通。**
+
+### Arena 附件上传限制
+白名单：`png webp jpeg gif txt md csv html xml css js json pdf` ——
+**没有 zip**。而且附件是**走内容通道进上下文，不落盘到沙盒**
+（`/home/user/uploads/` 实际不存在）。
+
+- 改后缀伪装成 pdf → 平台解析失败，文件根本进不来 ❌
+- base64 成 txt → 会把巨大字符串塞进上下文，不可行 ❌
+- **✅ 正解：让用户把文件传到 GitHub 仓库，agent 用 `git fetch` 取**
+
+### zip 中文文件名要特殊处理
+GitHub 上传的 zip 没带 UTF-8 标志位，`unzip` 出来是 `#U8d44#U6599` 乱码。
+用 Python 按 cp437 → utf-8/gbk 重新解码（见当时的解压脚本思路）。
+
+### Agent 的 GitHub 权限范围
+```
+✅ 代码读写、git push、开 PR
+❌ 开启 Pages（403 Resource not accessible by integration）
+❌ 读写 Actions 设置（403）
+```
+**仓库设置类操作必须用户自己在网页上点。**
+
+### GitHub Pages 已配置
+```json
+{ "source": { "branch": "main", "path": "/" }, "build_type": "legacy",
+  "https_enforced": true }
+```
+合并到 main 会自动重新部署，1–3 分钟生效。手机浏览器缓存很顽固，要强制刷新。

+## 八、Arena 平台机制（用户问过，已查证）
+
+**Agent Mode 不是固定模型**，每个 session 随机路由给一个模型，
+会话中途一般不变（除非某次回复可能失败，系统会自动切换）。
+反馈后**不揭示模型身份**。
+
+**Agent 排行榜**用「因果追踪（Causal Tracing）」而非 Elo/Bradley-Terry，
+得分是相对平均模型的**净改善度**。5 个等权信号：
+
+| 信号 | 含义 | 方向 |
+| --- | --- | --- |
+| Confirmed Success | 用户点「是/否」按钮（取任务轨迹**最终**那次） | 越高越好 |
+| Praise vs Complaint | 用户自然语言里夸奖 vs 抱怨 | 越高越好 |
+| Steerability | 用户纠正后能否改对 | 越高越好 |
+| Bash Recovery | 命令报错后几轮恢复 | 越少越好 |
+| Tool Hallucination | 有没有瞎编不存在的工具 | 越低越好 |
+
+文档：https://arena.ai/blog/agent-arena-methodology
+
+### 🔑 最重要的一条：session = PR 生命周期
+
+```
+建分支 → 改 → push → 改 → push …   ← 合并前迭代次数不限
+                        ↓
+                     合并 PR
+                        ↓
+                  session 结束，推送通道关闭
+```
+
+**教训：别急着点 Merge。** 上次用户第一版交付后立刻合并，
+导致后续想改都推不上去了。
+
+**想在合并前看线上效果**：`Settings → Pages → Branch` 下拉里能选**任意分支**，
+开发期间临时指向工作分支，push 就自动部署；满意后再切回 `main` 并合并。

+      return '<a href="' + esc(h) + '"' + ext + '>' + t + '</a>';
+    });
+    s = s.replace(/\*\*\*([^*]+)\*\*\*/g, '<strong><em>$1</em></strong>');
+    s = s.replace(/\*\*([^*]+)\*\*/g, '<strong>$1</strong>');
+    s = s.replace(/(^|[^*])\*([^*\n]+)\*/g, '$1<em>$2</em>');
+    s = s.replace(/~~([^~]+)~~/g, '<del>$1</del>');
+    s = s.replace(/\u0000C(\d+)\u0000/g, function (_, i) {
+      return '<code>' + codes[+i] + '</code>';
+    });
+    return s;
+  }

+  function splitRow(line) {
+    var t = line.trim().replace(/^\|/, '').replace(/\|$/, '');
+    return t.split('|').map(function (c) { return c.trim(); });

+  function renderMarkdown(src) {
+    var lines = src.replace(/\r\n?/g, '\n').split('\n');
+    var out = [], i = 0;
+
+    function listBlock() {
+      // 收集连续的列表行（含缩进嵌套）
+      var items = [];
+      while (i < lines.length) {
+        var m = /^(\s*)([-*+]|\d+[.)])\s+(.*)$/.exec(lines[i]);
+        if (!m) {
+          // 允许列表项内的续行
+          if (items.length && /^\s+\S/.test(lines[i]) && lines[i].trim()) {
+            items[items.length - 1].text += ' ' + lines[i].trim();
+            i++; continue;
+          }
+          break;
+        }
+        items.push({
+          indent: m[1].replace(/\t/g, '    ').length,
+          ordered: /\d/.test(m[2]),
+          text: m[3]
+        });
+        i++;
+      }
+      if (!items.length) return '';
+
+      var html = '', stack = [];
+      items.forEach(function (it) {
+        while (stack.length && it.indent < stack[stack.length - 1].indent) {
+          html += '</li></' + stack.pop().tag + '>';
+        }
+        if (!stack.length || it.indent > stack[stack.length - 1].indent) {
+          var tag = it.ordered ? 'ol' : 'ul';
+          if (stack.length) html += '<' + tag + '>';
+          else html += '<' + tag + '>';
+          stack.push({ indent: it.indent, tag: tag, first: true });
+        } else {
+          html += '</li>';
+        }
+        html += '<li>' + inline(it.text);
+      });
+      while (stack.length) html += '</li></' + stack.pop().tag + '>';
+      return html;
+    }
+
+    while (i < lines.length) {
+      var line = lines[i];
+
+      // 空行
+      if (!line.trim()) { i++; continue; }
+
+      // 围栏代码
+      var fence = /^\s*(```|~~~)(.*)$/.exec(line);
+      if (fence) {
+        var mark = fence[1], buf = [];
+        i++;
+        while (i < lines.length && !new RegExp('^\\s*' + mark).test(lines[i])) {
+          buf.push(lines[i]); i++;
+        }
+        i++;
+        out.push('<pre><code>' + esc(buf.join('\n')) + '</code></pre>');
+        continue;
+      }
+
+      // 标题
+      var h = /^(#{1,6})\s+(.*)$/.exec(line);
+      if (h) {
+        var lv = h[1].length;
+        out.push('<h' + lv + '>' + inline(h[2].replace(/\s*#+\s*$/, '')) + '</h' + lv + '>');
+        i++; continue;
+      }
+
+      // 分隔线
+      if (/^\s*([-*_])\s*(\1\s*){2,}$/.test(line)) {
+        out.push('<hr>'); i++; continue;
+      }
+
+      // 表格
+      if (/\|/.test(line) && i + 1 < lines.length &&
+          /^\s*\|?[\s:|-]+\|[\s:|-]*$/.test(lines[i + 1]) && /-/.test(lines[i + 1])) {
+        var head = splitRow(line);
+        var align = splitRow(lines[i + 1]).map(function (c) {
+          if (/^:.*:$/.test(c)) return ' style="text-align:center"';
+          if (/:$/.test(c)) return ' style="text-align:right"';
+          return '';
+        });
+        i += 2;
+        var body = [];
+        while (i < lines.length && /\|/.test(lines[i]) && lines[i].trim()) {
+          body.push(splitRow(lines[i])); i++;
+        }
+        var t = '<table><thead><tr>';
+        head.forEach(function (c, k) { t += '<th' + (align[k] || '') + '>' + inline(c) + '</th>'; });
+        t += '</tr></thead><tbody>';
+        body.forEach(function (r) {
+          t += '<tr>';
+          for (var k = 0; k < head.length; k++) {
+            t += '<td' + (align[k] || '') + '>' + inline(r[k] || '') + '</td>';
+          }
+          t += '</tr>';
+        });
+        out.push(t + '</tbody></table>');
+        continue;
+      }
+
+      // 引用
+      if (/^\s*>/.test(line)) {
+        var q = [];
+        while (i < lines.length && /^\s*>/.test(lines[i])) {
+          q.push(lines[i].replace(/^\s*>\s?/, '')); i++;
+        }
+        out.push('<blockquote>' + renderMarkdown(q.join('\n')) + '</blockquote>');
+        continue;
+      }
+
+      // 列表
+      if (/^(\s*)([-*+]|\d+[.)])\s+/.test(line)) {
+        out.push(listBlock());
+        continue;
+      }
+
+      // 段落
+      var p = [];
+      while (i < lines.length && lines[i].trim() &&
+             !/^(#{1,6}\s|\s*>|\s*([-*+]|\d+[.)])\s|\s*(```|~~~))/.test(lines[i]) &&
+             !/^\s*([-*_])\s*(\1\s*){2,}$/.test(lines[i])) {
+        p.push(lines[i].trim()); i++;
+      }
+      if (p.length) out.push('<p>' + inline(p.join(' ')) + '</p>');
+      else i++;
+    }
+    return out.join('\n');
+  }
