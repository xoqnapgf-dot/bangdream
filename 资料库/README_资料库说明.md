# MyGO!!!!! × Ave Mujica 资料库说明

## 资料库定位

本资料库围绕《BanG Dream! It's MyGO!!!!!》与《BanG Dream! Ave Mujica》整理，收录动画剧情、角色资料、官方访谈与设定、漫画与游戏内容、剧场版资料、社区解析及角色关系梳理。

这是非官方的中文资料整理项目。官方内容与社区观点分区收录，社区分析、考据与推测不代表 BanG Dream! Project、Bushiroad、动画制作团队或出演者的官方结论。

## 阅读注意事项

### 剧透

资料库包含完整剧情、结局、剧场版新增内容、人物经历和关系分析，阅读前请留意剧透。

### 内容性质

- 动画剧情、官方访谈、正式设定和商品信息属于可核对的官方内容。
- 社区解析、考据、角色解读、剧情推测与 CP 向内容属于作者或社区观点。
- 推测不应当作已确认剧情；存在争议的内容应结合原始来源判断。

### 原始底稿

动画台词、剧本、访谈原文和其他资料底稿原则上保持原貌。摘要用于辅助阅读，不替代需要保留的原文。

### 来源

带作者、日期和 URL 的出处集中列在相应文件末尾。引用访谈、档期、商品规格或社区文章时，建议同时查看原始页面。

### 图片与视频

部分页面使用官网、BanG Dream! 官方网站或官方 Bilibili 账号提供的远程图片和视频。资源可能因官网调整、地区限制或平台策略暂时无法加载；失效后应优先改用新的官方地址。

## 网站阅读

- 桌面端可使用左侧文件树和右侧本文大纲。
- 移动端可从顶部菜单打开文件树。
- 含手写文内目录的长文会显示浮动“目录”按钮，用于返回同页目录。
- 浏览器后退或前进时会恢复离开前的阅读位置。
- 下载完整仓库并保持原目录结构后，可直接双击根目录的 `index.html` 离线阅读。

## 内容整理原则

- 优先采用官网、官方公告、正式商品页和可访问的原始来源。
- 官方剧情、设定、访谈与社区解析、考据、推测保持明确区分。
- 相似内容不等于重复内容；删改前应确认是否存在不可替代的信息差异。
- 概括不能代替原文，不以跳转链接替代需要保留的完整长文。
- 无实际图片的图片占位不保留；可确认的图片失效时优先替换为可靠来源。
- 页面正文面向读者，不记录核验过程、修改过程或内部工作说明。
