# MyGO!!!!! × Ave Mujica 资料库说明

## 资料库定位

本资料库围绕《BanG Dream! It's MyGO!!!!!》与《BanG Dream! Ave Mujica》整理，收录动画剧情、角色资料、官方访谈与设定、漫画与游戏内容、剧场版资料、社区解析及角色关系梳理。

这是非官方的中文资料整理项目。官方内容与社区观点分区收录，社区分析、考据与推测不代表 BanG Dream! Project、Bushiroad、动画制作团队或出演者的官方结论。

## 阅读注意事项

### 剧透

资料库包含完整剧情、结局、剧场版新增内容、人物经历和关系分析，阅读前请留意剧透。

### 内容性质

- 动画剧情、官方访谈、正式设定和商品信息属于可核对的官方内容。
- 社区解析、考据、角色解读、剧情推测与 CP 向内容属于作者或社区观点。
- 推测不应当作已确认剧情；存在争议的内容应结合原始来源判断。
- 社区汇总应分别标明可观察剧情、可定位主创发言与评论者解释；资料库编辑正文不得仅凭角色片段行为作临床诊断、预测自杀风险或沿用污名化称呼；社区原帖中的诊断式猜测、风险预测、网络黑话和尖锐措辞可以作为接受史保留，但必须显著标注为原作者观点、非官方设定且非临床结论。重复长文只保留一份全文，其余位置以摘要和跨文件相对链接代替；追番期预测应保留当时语境并补充后续核验状态。
- 网页为每个文件显示精确到分钟的北京时间更新时间：已提交文件取 Git 最后修改提交，尚未提交或新建文件取生成时刻；文件系统 mtime 不作为历史依据。

### 原始底稿

动画台词、剧本、访谈原文和其他资料底稿原则上保持原貌。摘要用于辅助阅读，不替代需要保留的原文。

### 译名

同一角色或代号在库内只用一种中文写法，避免检索时只命中一半结果。

- Ave Mujica 中若叶睦的人格代号 **Mortis，中文统一写作「墨缇丝」**（`07_若叶睦/睦x墨缇丝.md` 即用此写法）。
- 英文原名 `Mortis`、`Timoris`、`Amoris`、`Oblivionis`、`Doloris` 在正文中保持英文，不强行中文化。
- 引用他人原文时保持原貌：繁體论文中的「莫爾提斯」「提莫里斯」等属引文，不随库内规范改写。

### 来源

带作者、日期和 URL 的出处集中列在相应文件末尾。引用访谈、档期、商品规格或社区文章时，建议同时查看原始页面。

详细逐话记录可以帮助恢复遗漏场景和连续对白，但不等同于官方剧本：《It's MyGO!!!!!》与《Ave Mujica》应按各自全 13 话共同核对，尤其复查跨作回忆、到场人物和事件边界。原句应放回其发生的剧情现场，并用动画画面、官方切片、带时间戳字幕或前后场景校正明显听写错误，不另建脱离上下文的名台词摘录表。整理连续对话时，应以场面、动作与情绪自然衔接人物原句，避免编辑式段首标签和堆叠「某人说、某人回答」式转述；这项润色不能改变说话人、先后顺序或删去理解对白所需的上下文。其中的感想、推测、人物动机判断、CP 评论和未来预测不写入剧情区。

### 图片与视频

部分页面使用官网、BanG Dream! 官方网站或官方 Bilibili 账号提供的远程图片和视频。资源可能因官网调整、地区限制或平台策略暂时无法加载；失效后应优先改用新的官方地址。

## 网站阅读

- 桌面端可使用左侧文件树和右侧本文大纲。
- 移动端可从顶部菜单打开文件树。
- 文件树里的目录标记只表示内容状态，不影响点击阅读：
  - **全锁**（`01_MyGO动画`、`02_AveMujica动画`、`05_官方访谈与设定`、`06_社区解析_推测`）——内容已基本确定，不再新增。
  - **半锁**（`03_剧场版`、`04_漫画游戏`、`07_CP线梳理`）——后续仍会随新资料补充更新。

  两种图标都只是提示，不影响点击和阅读；名单配置在 `assets/app.js` 顶部。
- 正文里点了跳转之后，窄屏右下角会按需浮出返回按钮：本页跳转显示「返回」，回到跳转前的位置；顺着交叉引用跳到别的资料则显示「上一页」，回到来源文件。没有跳转时不出现。
- 含手写文内目录的长文，窄屏下另会显示浮动“目录”按钮，用于返回同页目录；宽屏改用右侧本文大纲。
- 浏览器后退或前进时会恢复离开前的阅读位置。
- 下载完整仓库并保持原目录结构后，可直接双击根目录的 `index.html` 离线阅读。

## 内容整理原则

- 优先采用官网、官方公告、正式商品页和可访问的原始来源。
- 官方剧情、设定、访谈与社区解析、考据、推测保持明确区分。
- 相似内容不等于重复内容；删改前应确认是否存在不可替代的信息差异。
- 概括不能代替原文，不以跳转链接替代需要保留的完整长文。
- 无实际图片的图片占位不保留；可确认的图片失效时优先替换为可靠来源。
- 页面正文面向读者，不记录核验过程、修改过程或内部工作说明。
